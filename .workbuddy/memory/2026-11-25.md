# 2026-11-25

## 视频转实况图工具（E:\实况）

从零做了一个本地 Web 工具：视频片段 → 实况照片（Motion Photo / iOS Live Photo 配对）。

**技术栈**
- Flask 3.0.3 + 原生 JS 单页，无前端框架
- ffmpeg 6.0 便携版（`tools/ffmpeg/bin/`，从 npmmirror 拉 ffmpeg-static b6.0 的 gz，6 秒下完 28.9MB）
- 纯 Python 手写 TIFF/EXIF/XMP/Apple MakerNote，不依赖 exiftool（本机没有）

**关键实现点**
- Motion Photo = JPEG(APP1 EXIF + APP1 XMP) + 尾部追加 MP4，`GCamera:MicroVideoOffset` 填 MP4 字节数
- iOS 配对 = JPG 的 Apple MakerNote tag 17 + MOV 的 `com.apple.quicktime.content.identifier`，同一个 UUID
- ffmpeg 写 MOV 元数据**必须** `-movflags use_metadata_tags`，否则进 udta 的 © 标签，相册读不到
- Apple MakerNote 内部偏移相对 MakerNote 起点（不是相对 IFD/sub），踩过这个坑，读出半截 UUID
- `probe()` 要按 rotation 交换宽高（竖屏视频），`fit_size()` 保证宽高都是偶数（yuv420p 要求）

**踩坑**
- builder 里 motion 和 still 最初共用 `.jpg` 文件名，still 把 motion 覆盖了 → 端到端测试才暴露
- Playwright 自带 chromium 没装，改用 `executable_path` 指向系统 Chrome
- 时间轴选区原来看不清（缩略图太花 + 遮罩太暗），加粗边框/加深遮罩/加宽封面热区后才达标

**待办 / 已知限制**
- iOS 相册不能直接导入 JPG+MOV 对，需要 Live Photo Converter 一类工具，README 写明了
- 没做 exe 打包（PyInstaller 3.6 在本机，但有 PYTHONPATH shim 问题）
